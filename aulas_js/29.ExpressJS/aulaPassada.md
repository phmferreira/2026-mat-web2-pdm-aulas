# Requisição HTTP
## HTTP - Protocolo de transferência de Hipertexto

- cliente x servidor

## mensagem de requisição
* Método - ação requisitada
* Endpoint (url) - endereço do recurso
  * suap.ifpb.edu.br - servidor SUAP
  * suap.ifpb.edu.br/principal
  * suap.ifpb.edu.br/aluno (endpoint dos recursos associado a alunos)
* msg: head + body

## métodos
* GET: requisitar recurso
* POST: enviar recurso
* PUT/PATCH: atualizar recurso
* DELETE: remover recurso
